# Ananya Rawat | Data Analyst

Portfolio site, live at https://ananya3283.github.io.

Next.js (static export), Tailwind CSS v4, Motion. All copy lives in `src/content.ts`.

```bash
npm install
npm run dev     # local preview
npm run build   # static site in out/
```

Pushing to `main` deploys to GitHub Pages through `.github/workflows/pages.yml`.
